# Alho Zani — Website institucional

Site responsivo em HTML + CSS + JavaScript para a empresa Alho Zani, com as marcas/linhas Alho Maringá, Alho Zani e Alho Arapongas.

## Estrutura
- `index.html` — página principal.
- `style.css` — identidade visual, responsividade e componentes.
- `script.js` — catálogo, busca/filtro, modal de produtos, acordeão e formulário.
- `assets/` — imagens fornecidas e recortadas a partir dos anexos.

## Como executar
1. Mantenha a estrutura de pastas.
2. Abra `index.html` no navegador.
3. Para publicar, envie todos os arquivos para seu servidor/hospedagem.

## Formulário
O formulário é front-end: valida os campos, guarda um pequeno registro local no navegador e abre o WhatsApp da empresa com uma mensagem preenchida. Para receber e armazenar cadastros em banco de dados, conecte o formulário a um backend/API.

## Fotos dos pratos
As fotos da seção "Pratos que combinam com alho" usam imagens externas do Unsplash. Se desejar uma versão totalmente independente da internet, substitua essas URLs por fotografias próprias/autorizadas.

## Observação sobre informações de saúde
O conteúdo foi redigido como informação educativa geral, sem prometer efeitos terapêuticos. Para uso comercial definitivo, recomenda-se revisão por responsável técnico e adequação às normas de rotulagem e publicidade aplicáveis.
